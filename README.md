# Git Practice

Учебный проект для выполнения задания по Git.

## Цель

Практика базовых Git-команд:
- clone
- add
- commit
- push
- pull
- merge
- работа с ветками
- Pull Request

## Git workflow

Основной рабочий процесс:

1. Создание или изменение файлов
2. `git add` — добавление изменений в staging
3. `git commit` — создание коммита
4. `git push` — отправка изменений на GitHub
